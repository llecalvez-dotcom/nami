# Synthetic test documents

Fictional people, generated by a script. Every image is marked SPECIMEN; none is a replica of a real passport design and none may be used as an identity document. The machine-readable lines (MRZ) follow ICAO 9303 with valid check digits, so Nami's reader and MRZ checks run on them like on a real scan. `manifest.json` lists the expected fields.

Never upload these to a real government site: use them with the local copies of the forms only.

Regenerate: `python scripts/make-test-documents.py fixtures/test-documents` (needs Pillow).
