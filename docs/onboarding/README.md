# Onboarding Nami : tout pour repartir de zéro

Ce dossier est fait pour quelqu'un qui arrive sur le projet sans rien connaître : un développeur, ou un agent (Devin, Claude Code, Cursor, autre) chargé d'installer et de faire tourner Nami sur une machine neuve.

| Fichier | Contenu |
|---|---|
| [`installation.md`](installation.md) | **Installation complète, pas à pas, au millimètre** : prérequis, clés, `.env.local` variable par variable, Chrome de l'agent, pont `holo local browser`, extension, documents de démo, lancement, parcours de démo, scripts de test, vérifications, dépannage de tous les pièges rencontrés, architecture du code, règles pour un agent IA. |
| [`etat-et-suite.md`](etat-et-suite.md) | **Ce qui a été fait, ce qui reste à faire, les prochaines étapes** : état réel au 8 novembre 2026 au matin, limites volontaires, dette connue, ordre des chantiers. |

Les autres documents du dépôt restent la référence sur leur sujet : `docs/equipe/checklist.md` (chaque fonctionnalité et son état, à mettre à jour à chaque PR fusionnée), `docs/equipe/cockpit.md` (façon de travailler), `docs/specs/` (cadrage), `docs/tickets/` (une fiche par chantier), `docs/tests/` (un fichier par test réel), `extension/README.md` (l'extension Chrome en détail), `CLAUDE.md` et `AGENTS.md` (consignes pour les agents).
